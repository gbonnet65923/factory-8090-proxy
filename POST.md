# Пост для Telegram-канала (стиль @alstack)

---

🔥 **GPT-5.6 Sol, бесплатный и прямо в твоём терминале**

Пока все ищут, где взять топ-модель без подписок за $200 — один локальный прокси решает всё.

Что случилось: у factory.8090.ai есть свой веб-чат с топовыми моделями. Я завернул его в **локальный OpenAI-совместимый шлюз** — и теперь любым CLI-агентом (Cline, Roo Code, OpenCode, Continue, OMP) можно работать через их моделей, как будто это твой обычный API.

Что умеет коробка:

▪️ Дашборд на `127.0.0.1:18090` — вставил креды, всё работает
▪️ 4 способа подачи кредов, включая **авто-сбор консольной командой** — один клик, заголовки сами падают в буфер
▪️ Chrome-расширение: перехватывает auth-заголовки твоей сессии и **само пушит их в прокси** — ноль ручного копирования
▪️ Кнопки «установить в Cline / Roo / OpenCode / Continue / OMP» — конфиги CLI обновляются в один клик, как в 9router
▪️ Playground прямо в дашборде: модель, reasoning_effort, стриминг
▪️ Токены протухают через час? Отправил боту ещё одно сообщение — расширение обновило креды само

Как запустить (2 минуты):

```
git clone https://github.com/gbonnet65923/factory-8090-proxy
cd factory-8090-proxy
node server.mjs
```

Дальше: открываешь дашборд → «Способ 4» → вставляешь команду в консоль на factory.8090.ai → отправляешь боту любое сообщение → возвращаешься — модели уже на месте.

Ноль зависимостей. Чистый Node 22, stdlib only. OpenAI `/v1/chat/completions`, стриминг, tool choice — всё как у больших.
