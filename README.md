# Factory 8090 → Roo Code: локальный прокси

Нужен Node.js 20 или новее. Эта папка — весь комплект программы. HAR-файлы и созданные при работе `factory-session.json` и `factory-conversations.json` содержат данные сессии: не отправляйте их другим людям и не публикуйте.

1. В Chrome Откройте DevTools (`F12`) → **Network**, включите **Preserve log** и очистите список запросов. Включите разрешение на экспорт чувствительных данных в настройках DevTools (F1 - Network - Allow to generate HAR with sensitive data). Начните запись. 
2. В Chrome откройте `https://factory.8090.ai` и войдите в аккаунт. 
2. В Factory откройте Agent chat, выберите модель и отправьте короткое сообщение. Чтобы захватить данные для автоматического обновления токена, выполняйте запись Network с момента входа в аккаунт; если нужного запроса обновления в HAR нет, прокси сможет работать лишь до истечения текущей сессии.
3. Экспортируйте журнал Network как **HAR with sensitive data**. Скопируйте один или несколько `.har` файлов **в папку, рядом с `Start-Proxy.bat`**. В HAR должны быть запросы `api.factory.8090.dev` с заголовками авторизации и запрос Agent chat или списка моделей.
4. Запустите `Start-Proxy.bat`. В окне должно появиться `Factory proxy listening on http://127.0.0.1:18090/v1`. Оставьте окно открытым.
5. В Roo Code выберите **OpenAI Compatible**: Base URL `http://127.0.0.1:18090/v1`, API Key `local-trial`, модель — из списка, показанного при запуске прокси.

Прокси ищет `.har` только рядом с собой и выбирает подходящие данные из самых новых файлов. Если авторизация истекла и обновление токена недоступно, заново снимите HAR и перезапустите прокси. Для проверки запуска без API-ключа откройте `http://127.0.0.1:18090/health` — должен вернуться `{"status":"ok"}`.

## Дополнительно

- `GET /v1/status` (с тем же API-ключом) — список моделей, число активных сессий и срок действия авторизации (`auth.expiresAt`, epoch-мс; `null`, если автообновление токена не настроено).
- Каталог моделей обновляется с сервера Factory при старте; при неудаче тихо остаётся каталог из HAR.
- Ответы содержат поле `usage` с оценкой токенов (символы/4).
- Сетевые сбои и HTTP 502/503/504/429 при отправке сообщения в Factory повторяются один раз автоматически.
- Тесты: `npm test` (локальные, без сети).
